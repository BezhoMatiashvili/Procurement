# რა გვჭირდება კლიენტისგან ფაზა 1-ის ტესტირებისთვის

## დოკუმენტები (ანონიმიზებული)

თითოეული ტიპიდან 5–10 ცალი, სასურველია სხვადასხვა მიმწოდებლისგან/ფორმატით:

1. **მიმწოდებლის კომერციული წინადადება** — PDF (ქართული და ინგლისური; მინიმუმ 1–2 სკანირებული).
2. **BOQ Excel** — ცარიელი შაბლონი + 2–3 შევსებული სხვადასხვა ბიდერისგან ერთი ტენდერიდან.
3. **ხელშეკრულების draft** — DOCX (იურიდიულიდან მიღებული ფორმით).
4. **მიღება-ჩაბარების აქტი (AOA)** — DOCX/PDF, თანმხლებ ხელშეკრულებასთან ერთად.
5. **მინდობილობა** + რეესტრის სავარაუდო სტრუქტურა (ვინ, რაზე, რა ვადით).
6. **არსებული შედარებითი ანალიზის Excel** — ზუსტად იმ ფორმატში, რასაც დღეს ხელით აკეთებთ.

**ანონიმიზაციის წესი** (თუ სხვა არ გაქვთ): კომპანიის სახელი → „Company A/B/C“, ს/კ → გამოგონილი
9/11-ნიშნა კოდი, პირების სახელები → შეცვლილი, თანხები/ვადები/პირობები — **უცვლელი** (სწორედ
მათი ამოღება უნდა შემოწმდეს).

## ინფორმაცია

- თითოეული დოკუმენტის ტიპისთვის **რომელი ველები** გაინტერესებთ (ჩვენი სია: ფასი, ჯამური თანხა,
  დღგ, რაოდენობა, მიწოდების ვადა, შესრულების ვადა, გადახდის პირობები, გარანტია, მოქმედების ვადა,
  პირგასამტეხლო, თარიღი, ნომერი, მხარეები, ს/კ, დირექტორი — დაამატეთ/ამოიღეთ).
- სად დაიდგმება სისტემა: სერვერის სპეციფიკაცია (CPU/RAM/დისკი), OS, ვინ ადმინისტრირებს.
- მომხმარებლების რაოდენობა და ავთენტიფიკაციის სურვილი (AD/LDAP?).
- დოკუმენტების შენახვის ვადა (ჩვენი default: 7 დღე, შემდეგ ავტომატური წაშლა).
- ფაზა 3-ისთვის: დასაშვებია თუ არა სერვერიდან **ერთი** გარე მისამართის (მეწარმეთა რეესტრი)
  გამოძახება, თუ რეესტრის მონაცემები შიდა ექსპორტით მოგვაწოდებთ.

## როგორ დავტესტავთ

1. **ეტაპი A (ჩვენთან):** სინთეზურ + თქვენს ანონიმიზებულ დოკუმენტებზე; თითო ველისთვის ხელით
   შედგენილ „სწორ პასუხებთან“ შედარება (precision/recall). სამიზნე: ≥90 % თანხები/თარიღები,
   ≥80 % ტექსტური პირობები.
2. **ეტაპი B (თქვენთან):** სისტემა იდგმება თქვენს სერვერზე/ლეპტოპზე ინტერნეტის გარეშე.
   თანამშრომლები თავად ტვირთავენ **რეალურ** დოკუმენტებს; ჩვენ დოკუმენტებს ვერ ვხედავთ —
   მხოლოდ თქვენს უკუკავშირს და audit-ლოგის სტატისტიკას.
3. **ეტაპი C:** უსაფრთხოების ჩეკლისტი (OWASP ASVS L2 ქვესიმრავლე) + `docs/SECURITY.md`
   თქვენი IT/უსაფრთხოების გუნდისთვის.
