კურსით; ხელშეკრულებასთან შედარება (მხარეები, საგანი, საკადასტრო, ვადა, ღირებულება, გადახდის

### ტესტმა გამოავლინა და გასწორდა (კოდში)
1. Docling-ის markdown-ში **bold** მარკერები (`**100** (ასი) ლარს`) და inline-run-ების **newline**-ები
   არღვევდა regex-ებს → chunk-ტექსტი ახლა ფორმატირების გარეშეა, newline აღარ არის წინადადების საზღვარი.
2. ქართული keyword-ები პრეფიქსიანი სიტყვების შიგნით („სა**ფას**ური“) — substring matching ქართულისთვის.
3. გადაფარვადი თარიღების ორმაგი დათვლა („1 აგვისტოდან 2026“); OCR-ის „2026. წლის“.
4. ახალი ტიპები: `bank_account` (IBAN/SWIFT), `cadastral_code`; დაუკლასიფიცირებელი თანხები/თარიღები
   აღარ იკარგება (label „unclassified“).
5. Docker: `/data` volume-ის ownership (app user ვერ წერდა named volume-ში).

## 6. Wrong One — LLM pass (gemma3:4b, 4 chunk, 577 წმ)

LLM-მა ამოიღო ის, რაც rules-ს არ შეუძლია: კომპანიის დასახელება „შპს ნიმუში“, დირექტორები

LLM-შედეგთან შედარებით `aoa_check.py`-მ დააფიქსირა ზუსტად სამი რეალური შეუსაბამობა:
